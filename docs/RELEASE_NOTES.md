# 爽听 V2.0 — 首个公开发布版

> 插件化音乐播放器，Android / Windows 双端，默认简体中文，可切换 English。
> 默认强调色：森林。

## 功能一览

### 音源与插件

- **插件音源**：QuickJS 运行 MusicFree CommonJS 插件，内置 `axios / cheerio / crypto-js / dayjs / qs / he / big-integer / cookies` 兼容模块。
- **插件管理**：URL / 本地文件安装、订阅链接、启用停用、排序、变量配置、远程更新、卸载、首次运行订阅引导。
- **搜索**：单曲 / 专辑 / 作者 / 歌单 / 歌词五类搜索；跨音源按相关度聚合，多源命中优先；卡片末尾标注所属音源；不显示冗余音源分类标签。

### 发现与榜单

- **每日推荐**：发现页顶部每日推荐卡片，按日期从热歌池随机抽 10 首，当天固定；软件打开后默认播放每日推荐。
- **全源热歌**：前 6 个音源聚合，来源标注，点击即可连队列播放。
- **聚合榜单**：跨音源榜单聚合，榜单卡片可直接进入详情（修复空白页）。
- **推荐歌单**：标签筛选、分页加载；各插件独立榜单与推荐内容。

### 播放体验

- **播放队列**：顺序 / 列表循环 / 单曲循环 / 随机，上一首 / 下一首、播放全部、添加到队列、移动与删除。
- **播放控制**：进度拖动、倍速（长按播放键临时 2x）、定时关闭、失败自动换源、断点续播。
- **远程音频本地代理**：为需要 Referer / Cookie / UA 的音源补请求头。
- **喜欢与收藏**：我喜欢、自建歌单（新建 / 重命名 / 删除 / 排序）、单曲与歌单导入。
- **历史记录**：最近播放、按时间聚合。

### 歌词与车机

- **歌词**：逐行同步、点击跳转、字号调节、搜索、跨音源自动匹配、关联到其他歌曲、歌词时间偏移。
- **蓝牙歌词**：将当前歌词行写入 Android 蓝牙媒体信息（专辑 / 副标题字段），便于车机显示。
- **横屏 / 车机播放页**：大尺寸黑胶封面 + 音源标记，右侧大字号歌词与歌曲信息，底部整条进度与主控区。
- **Android 媒体通知**：常驻通知、封面、进度、上一首 / 播放暂停 / 下一首、锁屏控制、通知栏「喜欢 / 取消喜欢」快捷按钮。
- **音频会话**：按媒体场景配置，蓝牙 / 车机路由、耳机断开自动暂停、来电打断后恢复。

### 本地与数据

- **本地音乐**：文件夹扫描、ID3 元数据与内嵌封面读取。
- **下载管理**：并发数配置、进度、取消、断点文件、下载目录。
- **数据备份**：WebDAV 备份 / 恢复、本地 JSON 导出 / 导入。
- **个性化**：6 套强调色（默认森林）、明暗 / 跟随系统、背景图 + 透明度 + 模糊、中英双语。
- **Windows 托盘**：托盘图标、显示主窗口、播放 / 暂停、下一首、退出；关闭窗口默认最小化到托盘。

### 更新

- **应用内在线更新**：读取 GitHub Releases 最新版本，Android 直接下载 APK 并拉起系统安装器；启动时静默检查，可手动检查、跳过指定版本。
- **自动发版**：推送 `v*` 标签触发 GitHub Actions，自动构建三个 ABI 的 Release APK 并生成本说明。

## V2.0.1 性能更新

- 首页插件预热延迟到首帧后 350ms，避免刚进主页时 QuickJS 运行时创建阻塞主线程。
- 聚合榜单首批只拉 1 个音源（原为 2 个），后续源间隔 400ms 逐批补齐。
- 每日推荐启动播放延后 2 秒，避免与插件预热和网络请求争抢主 isolate。
- 启动时插件预热上限降为 1。

## 下载

选择对应 ABI 的 APK：

- `app-arm64-v8a-release.apk` — 主流 64 位 Android 设备
- `app-armeabi-v7a-release.apk` — 老款 32 位设备
- `app-x86_64-release.apk` — x86_64 设备 / 模拟器

安装后需自行安装 MusicFree 插件才能使用在线音源。
