听过就缓存，

爽听是一款自己设计界面的音乐播放器：在线曲库、自动离线缓存、逐字歌词、车机横屏与自动更新，一次做好。

为长时间听歌做的

不是把网页塞进壳里，播放、缓存、歌词都是原生实现。

⏯

在线曲库

搜索、榜单、歌单、专辑、歌手、每日推荐、私人 FM 与评论。

💾

自动缓存

听过的歌自动落盘，断网优先离线播放；LRU 清理，上限可调。

🎤

逐字歌词

KRC 解码，卡拉 OK 高亮、辉光、字号与偏移微调。

🚗

车机模式

横屏大按钮布局，宽屏自动进入，也可在设置中切换。

✅

每日签到

启动自动签到「爽听 VIP」，绑定 Cookie 后同步账号签到。

🔄

自动更新

读取 GitHub Releases，Android 直接装 APK，Windows 替换重启。

界面

深色为主，封面取色，桌面与手机共用一套布局。

下载与安装

所有构建由 GitHub Actions 自动产出。

选择你的平台

Android 提供按 ABI 拆分的 APK，Windows 提供免安装 zip。应用内「检查更新」会读取最新 Release。

Android · arm64-v8a绝大多数手机 → Android · armeabi-v7a旧设备 → Windows · x64解压即用 →

自己构建

需要 Flutter 3.47 或更新版本。

依赖flutter pub get
Androidflutter build apk --split-per-abi
Windowsflutter build windows
