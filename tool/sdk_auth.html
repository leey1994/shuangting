1//! Authentication APIs (QR login, SMS send + login, token refresh, device registration, …).
2//!
3//! # Login paths
4//!
5//! - **QR:** [`AuthApi::qr_key`] → [`AuthApi::qr_login_url`] → poll [`AuthApi::check_qr`]
6//!   (responses remain raw [`serde_json::Value`]; successful poll updates [`crate::Session`]).
7//! - **SMS:** [`AuthApi::send_sms_code`] then [`AuthApi::login_by_sms`]
8//!   (`POST /v7/login_by_verifycode`, Standard + Lite).
9//! - **Refresh:** [`AuthApi::refresh_token`] when the token is still valid.
10//! - **Device:** [`AuthApi::register_dev`] obtains a real `dfid` (helps avoid tracker SSA 20028).
11//!
12//! # Device identity (host injection)
13//!
14//! Prefer [`crate::DeviceIdentity::builder`] with a **stable** host id
15//! (`android_id` / IMEI / install id), persist the whole [`crate::Session`], and
16//! call [`AuthApi::register_dev`] **before** the first SMS when
17//! [`crate::Session::has_dfid`] is false.
18//! Do **not** use [`crate::Session::random`] for production login — re-rolling
19//! mid/uuid looks like a new device and raises 风控.
20//!
21//! ```rust,no_run
22//! # async fn demo(client: &kugou_sdk::KugouClient) -> kugou_sdk::Result<()> {
23//! use kugou_sdk::{DeviceIdentity, Session};
24//!
25//! let device = DeviceIdentity::builder()
26//!     .device_id("android_id_or_install_id")
27//!     .uuid("persisted-uuid")
28//!     .brand("Xiaomi")
29//!     .model("MI 14")
30//!     .imei("860123456789012") // optional; Lite t2 middle = MD5(imei)
31//!     .build()?;
32//! let mut session = Session::new(device);
33//! if !session.has_dfid() {
34//!     client.auth().register_dev(&mut session, None).await?;
35//! }
36//! // session.export()?  // persist mid/uuid/dfid
37//! client.auth().send_sms_code(&mut session, "13800138000").await?;
38//! # Ok(()) }
39//! ```
40//!
41//! See `docs/protocol/login.md` for wire fields and native `libj.so` notes.
42//!
43//! # Token refresh
44//!
45//! [`AuthApi::refresh_token`] calls `POST /v5/login_by_token` to extend an existing
46//! login. Request crypto (body `p3` / `params` / `pk`) lives in the private `crypto`
47//! module.
48//!
49//! Upstream **error_code 20017** is “登录信息过期” — the token is already invalid
50//! and QR/SMS re-login is required (refresh cannot resurrect an expired token).
51//!
52//! # SMS login crypto
53//!
54//! Same ephemeral AES + RSA `pk` pattern as token refresh. Credentials
55//! `{mobile, code}` are AES-encrypted into `params`; the wire `mobile` field is
56//! a masked display form. Lite attaches AES device fingerprints `t1`/`t2`/`dev`
57//! (or host `t*_override`). Standard defaults to open-compatible `t1=0`/`t2=0`
58//! unless [`crate::FingerprintMode::LiteAesOnStandard`] or overrides are set.
59//!
60//! Official t1/t2 live in **`libj.so`** (not `libkugouplayer`); Lite AES in this
61//! crate matches that algorithm. t2 plaintext is
62//! `guid|MD5(IMEI)|mac|MODEL|ms` (IMEI missing → open-compatible fixed MD5).
63//!
64//! # Device registration crypto
65//!
66//! [`AuthApi::register_dev`] uses playlist-style AES-128-CBC (Base64 body) + RSA
67//! PKCS#1 v1.5 query `p`, matching KuGouMusicApi `register_dev` / official
68//! `UpdateDeviceFingerProtocol` (`POST /risk/v2/r_register_dev`). When
69//! `device_info` is `None`, the fingerprint is built from
70//! [`crate::DeviceIdentity`] (host brand/model/uuid/…).
