1//! Async, typed SDK for a focused subset of KuGou Music APIs.
2//!
3//! # Design
4//!
5//! - **Explicit session:** device identity and login state live in [`Session`], not
6//!   inside [`KugouClient`]. Every request takes `&mut Session` so auth changes are
7//!   visible and serializable (`Session::export` / [`Session::import`]).
8//! - **Platform profiles:** [`PlatformProfile::Standard`] vs [`PlatformProfile::Lite`]
9//!   fix appid / salts / `clientver` for the client lifetime.
10//! - **Soft responses:** high-churn upstream JSON is mapped to stable SDK types
11//!   ([`SongRef`], [`SearchSongs`], [`PlaybackInfo`], …). Soft `from_value` never
12//!   fails on missing or renamed keys; leftovers go to each type's `extra` map.
13//!   For the business payload as-is, call the matching `*_raw` method.
14//!   [`ApiResponse::extra`] holds **envelope** fields only (no second copy of
15//!   business `data`); [`ApiResponse::headers`] is a diagnostic allowlist and
16//!   never includes `Set-Cookie`.
17//!
18//! KuGou endpoints are **not** a public stable API. Fields, signatures, and
19//! availability may change with official clients. Prefer this crate for learning
20//! and protocol research; respect platform terms and copyright.
21//!
22//! # Quick start
23//!
24//! ```no_run
25//! # async fn example() -> kugou_sdk::Result<()> {
26//! use kugou_sdk::{KugouClient, PlatformProfile, Session, SearchRequest};
27//!
28//! let client = KugouClient::builder()
29//!     .platform(PlatformProfile::Standard)
30//!     .build()?;
31//! let mut session = Session::random();
32//! let songs = client
33//!     .search()
34//!     .songs(&mut session, SearchRequest::new("海阔天空"))
35//!     .await?;
36//! for (i, hit) in songs.data.items.iter().enumerate() {
37//!     println!("#{i} {} {:?}", hit.display_name(), hit.primary_hash());
38//! }
39//! # Ok(()) }
40//! ```
41//!
42//! See the repository `README.md` and `docs/` for protocol notes, changelog, and
43//! the interactive `test_client` example.
44//!
45//! # Logging
46//!
47//! This crate uses the [`log`](https://docs.rs/log) facade only — it never installs
48//! a global logger. If the host does not call `log::set_logger` (or an equivalent
49//! such as `env_logger::init`), all macros are no-ops.
50//!
51//! | Level | Target | Content |
52//! |-------|--------|---------|
53//! | `debug` | `kugou_sdk::protocol` | One line per HTTP call: method, **redacted** URL (`token`/`signature` → `***`), status, elapsed, body lengths |
54//! | `debug` | `kugou_sdk::client` | Client build summary (platform, timeout, proxy yes/no) |
55//! | `debug` | `kugou_sdk::protocol` | Upstream business `error_code` + short message (still returned as [`KugouError::Business`]) |
56//! | `warn` | `kugou_sdk::protocol` | HTTP non-2xx, SSA `ssa-code` challenges, truncated bodies |
57//! | `trace` | `kugou_sdk::protocol` | Full wire dump (URL **with** secrets, headers including `Set-Cookie`, bodies) |
58//!
59//! **Do not enable `trace` in production** — it intentionally includes tokens and
60//! cookies for protocol investigation.
61//!
62//! ```text
63//! RUST_LOG=kugou_sdk=debug
64//! RUST_LOG=kugou_sdk::protocol=trace
65//! ```
66//!
67//! Hosts typically add `env_logger` (or `tracing` + `tracing-log`) and call
68//! `try_init` once at process start. The `test_client` example does this with a
69//! default filter of `warn`.
